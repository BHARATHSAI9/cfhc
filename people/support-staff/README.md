# support staff

drop support staff photos in this folder.

same idea as the coaches folder: name each file after the person, since we will
use the file name as the title on the site later. so `Anita Rao.jpg` shows up as
"Anita Rao".

a few tips:
- one photo per person.
- square-ish photos look best in cards.
- jpg or png is fine.
